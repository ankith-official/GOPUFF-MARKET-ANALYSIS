## 📌 Project Overview

This repository contains an exploratory data analysis (EDA) notebook designed to clean, transform, and analyze retail sales data from Gopuff (`gopuff_data.csv`).

Key highlights of the workflow:
* **Data Inspection:** Inspecting dataset structure, sizes, and data types.
* **Data Preprocessing & Cleaning:** Standardizing inconsistent categories within `Item Fat Content` (`LF`, `low fat` $\rightarrow$ `Low Fat`, `reg` $\rightarrow$ `Regular`).
* **KPI Calculations:** Summarizing total sales, average sales, total items sold, and mean product ratings.
* **Data Visualization:** Proportionate breakdown of total sales by item fat content using Matplotlib.
